# API de Alunos

API REST desenvolvida em **Spring Boot** para gerenciamento de alunos.

A aplicação permite realizar operações de **CRUD**:

* Cadastrar alunos
* Listar alunos
* Buscar aluno por ID
* Atualizar alunos
* Remover alunos

Os dados são armazenados em memória utilizando uma `List<Aluno>`, com separação entre **Controller, Service e Repository**.
